# Gait Diffusion

Two-stage latent diffusion for full-body gait generation conditioned on UPDRS
gait severity (0 = Normal, 1 = Mild, 2 = Moderate, 3 = Severe).

The pipeline takes CARE-PD SMPL sequences, converts them to the HumanML3D
263-dimension representation, compresses them with a 1D convolutional VAE into
a clinically-structured latent space, trains a Diffusion Transformer (DiT) to
denoise severity-conditioned latents, and generates full-body gait sequences.
Generation is conditioned on the UPDRS class via AdaLN-Zero + classifier-free
guidance, with an auxiliary range-of-motion (ROM) loss on the decoded output.

## Repository layout

```
gait-diffusion/
├── config.py                       # all configuration (env-overridable)
├── smpl_to_angles.py               # SMPL forward kinematics + geometric angles
├── h3d_bridge.py                   # H3D -> anatomical angles / clinical metrics
├── h3d/                            # vendored HumanML3D conversion package
├── preprocessing/
│   ├── preprocess_carepd.py        # subject-split loader + angle windowing
│   ├── preprocess_carepd_h3d.py    # CARE-PD SMPL -> H3D 263-dim windows
│   └── compute_fullbody_targets.py # recompute ROM / arm-swing / trunk targets
├── training/
│   ├── vae_updrs.py                # VAE architecture + losses
│   ├── train_vae.py                # Stage 1: VAE training
│   ├── model_updrs_dit.py          # DiT architecture
│   └── train_dit.py                # Stage 2: DiT training
├── generation/
│   └── generate.py                 # Stage 3: generation
└── evaluation/
    ├── synthetic.py                # biomechanical fidelity (ROM / DTW / KNN)
    ├── generalization.py           # TRTR / TSTR / TRTS
    ├── distributional.py           # FID / MMD / precision-recall
    └── gaitgen.py                  # AVE / AAMD / ASMD
```

```
pip install -r requirements.txt
```

## Data layout (expected on disk)

The raw CARE-PD dataset is third-party and license-restricted, so it is not
distributed with this repository. Place the downloaded files in the standard
folder layout below; the pipeline reads these paths directly from `config.py`:

```
gait-diffusion/
├── data/
│   ├── smpl_models/
│   │   └── basicmodel_neutral_lbs_10_207_0_v1.1.0.pkl   # SMPL model (smplx)
│   └── carepd/
│       ├── doi-10.5683-sp3-twikmk/                      # CARE-PD dataset
│       │   ├── BMCLab.pkl
│       │   ├── PD-GaM.pkl
│       │   ├── 3DGait.pkl
│       │   ├── T-SDU-PD.pkl
│       │   └── folds/
│       │       └── UPDRS_Datasets/                       # fixed subject splits
│       │           ├── BMCLab_6fold_participants.pkl
│       │           ├── PD-GaM_6fold_participants.pkl
│       │           ├── 3DGait_6fold_participants.pkl
│       │           └── T-SDU-PD_6fold_participants.pkl
│       └── (processed .npy / .pt artifacts generated by preprocess_carepd_h3d.py)
└── models/                                               # user-supplied checkpoints
    ├── gait_vae_updrs_h3d_lam03_4class.pth               # reference VAE
    ├── gait_updrs_dit_h3d_pw03_no_arm_rom_4class_ep2500.pth  # DiT
    └── gait_updrs_dit_h3d_stats.pt                       # normalization stats
```

All data, model, and generated-output paths can be overridden via environment
variables (see `config.py`). The default model paths are:

| Variable | Default |
|---|---|
| `UPDRS_MODEL_PATH` | `models/gait_updrs_dit_h3d.pth` |
| `UPDRS_VAE_MODEL_PATH` | `models/gait_vae_updrs_h3d.pth` |
| `UPDRS_STATS_PATH` | `models/gait_updrs_dit_h3d_stats.pt` |
| `UPDRS_GEN_OUTPUT_PATH` | `generated_data/generated_gait_updrs_dit_h3d.npy` |

The CARE-PD cohort pkl files must be preprocessed to the fixed subject splits
(`*_fixed.pkl`) expected by `preprocessing/preprocess_carepd.py`.

## Pipeline

Run all commands from the repository root.

### Stage 0 — Preprocessing

```
python -m preprocessing.preprocess_carepd_h3d
python -m preprocessing.compute_fullbody_targets
```

`preprocess_carepd_h3d.py` converts the CARE-PD SMPL sequences into HumanML3D
(263-dim) windows and writes `train_gait_h3d.npy`, `eval_gait_h3d.npy`,
`norm_params_h3d.pt`, and label/laterality/subject arrays under `data/carepd/`.
`compute_fullbody_targets.py` recomputes the arm-swing and trunk-inclination
targets used by the auxiliary losses.

### Stage 1 — VAE training

```
python -m training.train_vae
```

Trains the 1D convolutional VAE (263 -> 64 latent channels, 96 -> 24 time
steps) with a surrogate UPDRS classification head and class-prototype loss.
Save the checkpoint with a suffixed `UPDRS_VAE_MODEL_PATH` so training output
does not overwrite a reference model.

### Stage 2 — DiT training

```
python -m training.train_dit
```

Trains the Diffusion Transformer to denoise severity-conditioned latents with
classifier-free guidance and an auxiliary ROM loss on the decoded output. Set
`UPDRS_VAE_MODEL_PATH` to the Stage-1 VAE and `UPDRS_MODEL_PATH` to a suffixed
output name.

### Stage 3 — Generation

```
python -m generation.generate
```

Generates full-body gait sequences per UPDRS class. Paper settings:
guidance scale 1.5, temperature 1.0, `CFG_DROPOUT_PROB` 0.25. Set
`UPDRS_MODEL_PATH` / `UPDRS_VAE_MODEL_PATH` / `UPDRS_STATS_PATH` to the
trained models before generating.

### Evaluation

```
python -m evaluation.synthetic        # ROM / DTW / diversity / KNN
python -m evaluation.generalization   # TRTR / TSTR / TRTS
python -m evaluation.distributional   # FID / MMD / precision-recall
python -m evaluation.gaitgen          # AVE / AAMD / ASMD
```

Each eval script reads the generated samples (via `UPDRS_GEN_OUTPUT_PATH` or a
`--gen_path` flag), the real eval data, and the VAE, and writes a report under
`graphs/`.

## Notes

- The generated sample count, guidance scale, temperature, and all loss
  weights are configurable through `config.py` or environment variables.
- Raw CARE-PD pkl files and the SMPL model are not redistributed; obtain them
  from their respective sources and place them in the layout above.
